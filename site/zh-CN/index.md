**用 Morse Code 聊天。** DitMesh 基于 Tox，提供只能通过触摸或物理键盘直键/双桨输入的单聊和群聊，接收端按自选速度播放。Android、iOS、macOS、Linux、Windows 统一提供聊天产品。

网络设置支持自动或手动引导节点、节点可达性测试和桌面局域网节点托管。同一局域网内其他设备可将主机显示的地址、端口及 DHT 密钥配置为手动引导节点。界面提供十种语言和五种视觉风格。

设备本地生成 Tox 身份，不需要中心服务器注册、手机号或邮箱；没有 DitMesh 聊天或推送服务器。独立的 [MorseCQ](https://github.com/agentx-icu/morsecq) 应用提供无账号的离线学习。
