DitMesh 是 Android、iOS、macOS、Linux、Windows 上的点对点 Morse 聊天应用。没有开发者聊天服务器、中心注册或广告。支持使用公开 GitHub issues，请勿发布私密消息、身份或备份。

Android 正式版会在启动 Tox 后端前请求用户同意隐私政策。应用在本机保存已同意的政策版本，版本更新后会再次请求同意。

## 本地数据

应用在私有目录保存 Tox 身份、联系人、群组、历史、草稿、书签、练习数据、偏好、按键配置和主动保存的录音。身份档案可用密码保护；历史和练习文件没有静态加密，需要保护设备和备份。只有用户主动要求才保存或分享加密导出文件。

引导节点设置在本次安装中共用。桌面局域网托管使用单独的本地节点档案；更换或删除聊天身份会保留这些网络设置。

「我的 → 删除身份」删除本地账号数据；已发送消息保留在接收者设备。操作系统备份及之前导出的副本遵循各自保留规则。DitMesh 与 MorseCQ 的应用数据独立。

## 网络数据

消息和个人资料通过 Tox 加密发送给联系人或群组。公共引导节点帮助发现其他节点，没有开发者服务器保存未送达消息。离线消息在发送者设备等待，双方可达时送达。

自动引导和主动刷新列表会请求 `https://nodes.tox.chat/json`，该服务器能看到连接的 IP 地址。节点测试向选定地址发送 DHT 请求。桌面局域网托管打开 UDP 端口，并显示可主动分享的局域网地址及 DHT 公钥；这些节点信息不包含聊天身份私钥。

Tox 直接连接好友，不向好友隐藏彼此 IP 地址。引导/DHT 节点能够看到网络连接，使用临时 DHT 密钥；公开 Tox ID 本身不能公开私密身份密钥。参见 [Tox 官方隐私说明](https://tox.chat/faq.html)。显示名、状态和群组消息对目标联系人或群成员可见。

Android 版使用 Google ML Kit 在设备上扫描二维码。Google 会收到应用版本、设备信息和扫描性能等诊断及使用指标。摄像头图像和解码后的二维码内容均在本机处理，不会发送给 Google。

## 定位和附近的人

定位及附近可见性是独立的可选开关，在此设备的每个身份下默认关闭。当前坐标可填入 Maidenhead 网格定位工具；未发送的坐标仅保留在内存，不进入导出备份。你可在预览坐标并确认后，向联系人或群组主动发送单次位置消息；该消息保存在各接收方的聊天历史中，并随历史备份。查看收到的位置不读取本机定位；只有主动打开地图时才向地图提供方发送所选坐标。应用仅在前台读取位置。

同时开启附近可见性并打开「附近的人」后，DitMesh 使用与 Toxee 相同的 Tox rendezvous 协议。DitMesh 会在你所在区域的公开 Tox 群组中分享你的显示名和约 100 米精度的坐标。任何加入这些群组的人都可以收到这些信息。加入群组无需验证身份或实际位置。发现数据不进入普通聊天、历史或群组列表，没有位置目录服务器。网络及操作系统定位提供方对网络连接、定位请求有各自的数据处理方式。

每次发现会话生成新的签名及加密身份。只有明确发送或回应附近请求时才向选中的参与者分享 Tox ID，请求经过定向加密，成为好友仍需接受。关闭附近页面五分钟后停止发现；隐藏或挂起应用、关闭定位或附近可见性、断开 Tox 会话都会立即停止。会话记录会过期，但其他参与者可能保留已经收到的信息。附近屏蔽仅针对当前临时发现身份及会话，普通聊天屏蔽单独生效。

## 可选权限

- 局域网（Apple 平台）：连接手动配置的局域网节点，或在桌面端托管局域网节点。
- 定位：当前坐标、网格定位、主动发送聊天位置消息和可选的附近的人；不申请后台定位权限。
- 摄像头：设备本地扫描 Tox ID 二维码。
- 麦克风：本地解码 Morse 音频；仅在主动要求时保存录音。
- 通知：本地消息提示与跳转，没有推送服务器。
- 文件选择/分享：主动导入导出备份和材料。选择的云文件提供方或浏览器链接使用其自身网络服务。

## 屏蔽与更新

屏蔽会在本机隐藏该对象的消息、申请和邀请。没有能删除其他节点已保存消息的中心运营方。数据处理发生变化时会更新本页日期。
