DitMesh 是 Android、iOS、macOS、Linux、Windows 上的点对点 Morse 聊天应用。没有开发者聊天服务器、中心注册、广告、分析统计或跟踪代码。支持使用公开 GitHub issues，请勿发布私密消息、身份或备份。

## 本地数据

应用在私有目录保存 Tox 身份、联系人、群组、历史、草稿、书签、练习数据、偏好、按键配置和主动保存的录音。身份档案可用密码保护；历史和练习文件没有静态加密，需要保护设备和备份。只有用户主动要求才保存或分享加密导出文件。

「我的 → 删除身份」删除本地账号数据；已发送消息保留在接收者设备。操作系统备份及之前导出的副本遵循各自保留规则。DitMesh 与 MorseCQ 的应用数据独立。

## 网络数据

消息和个人资料通过 Tox 加密发送给联系人或群组。公共引导节点帮助发现其他节点，没有开发者服务器保存未送达消息。离线消息在发送者设备等待，双方可达时送达。

Tox 直接连接好友，不向好友隐藏彼此 IP 地址。引导/DHT 节点能够看到网络连接，使用临时 DHT 密钥；公开 Tox ID 本身不能公开私密身份密钥。参见 [Tox 官方隐私说明](https://tox.chat/faq.html)。显示名、状态和群组消息对目标联系人或群成员可见。

## 可选权限

- 摄像头：设备本地扫描 Tox ID 二维码。
- 麦克风：本地解码 Morse 音频；仅在主动要求时保存录音。
- 通知：本地消息提示与跳转，没有推送服务器。
- 文件选择/分享：主动导入导出备份和材料。选择的云文件提供方或浏览器链接使用其自身网络服务。

## 屏蔽与更新

屏蔽会在本机隐藏该对象的消息、申请和邀请。没有能删除其他节点已保存消息的中心运营方。数据处理发生变化时会更新本页日期。
