**Chat in Morse code.** DitMesh is the Morse-only direct and group messenger over Tox. Use a touch or physical-keyboard straight key/iambic paddles; messages replay locally at your preferred speed. Android, iOS, macOS, Linux and Windows share the same chat product.

Network settings support automatic or manual bootstrap nodes, node reachability tests and desktop LAN hosting. Devices already on that LAN can use the host's displayed address, port and DHT key as a manual bootstrap node. The interface offers ten languages and five visual styles.

Your device creates a Tox identity without central registration, phone number or e-mail. There is no DitMesh messaging or push server. The separate [MorseCQ](https://github.com/agentx-icu/morsecq) app provides offline learning with no account.
