# 定位与附近的人

[English](./LOCATION_AND_NEARBY.md)

每个身份在此设备上的定位默认关闭。在 **我 → 定位** 中授予前台定位权限，
点击 **使用当前位置** 查看坐标和 Maidenhead 网格。在 **参考 → 无线电工具 →
网格定位** 中点击同名按钮，可填入经纬度及本方网格，对方网格保持不变。
聊天菜单提供「发送当前位置」；确认后向当前聊天发送一次坐标，群聊会分享给所有群成员。接收的位置显示为卡片，包含坐标、网格和发送时间，可打开地图或复制坐标。一对一聊天的「查看分享的位置」读取对方最近的有效快照，即使定位主开关关闭也可查看，不会请求本机定位。位置卡片不会进入摩尔斯自动播放。

开启 **对附近的人可见** 并接受说明后，从联系人、添加好友或定位设置打开
**附近的人**。它向约 5 公里内的参与者分享显示名和约 100 米精度的坐标。
只开启定位即可使用网格工具，无需开启附近发现。功能不使用位置目录服务器，
与 Toxee 使用相同的 `toxee/nearby/v1` 协议，可以发现兼容客户端。发现网格仅用于
传输，不会成为聊天群组或进入消息历史。

**打招呼** 在确认分享 Tox ID 后向选定对象发送加密意向。接收者可拒绝或发送
Tox 好友申请，发起者仍需在申请收件箱主动接受。匹配的回复同时显示附近名称
及发送者公钥。名称、坐标及请求随机数不能证明现实身份。附近屏蔽仅隐藏本次
会话中的临时发现身份，聊天和联系人屏蔽独立生效。

退后台、隐藏应用、关闭任一开关、断开 Tox 会话或替换身份都会停止发现。关闭
附近页面五分钟后停止，再次打开会取消计时。回到前台时只在附近页面仍打开的
情况下恢复。删除或替换身份会清除其定位同意。未发送的坐标、临时密钥及附近可见性不进入导出备份；主动发送或收到的位置消息作为聊天历史保存，并随历史备份。

`LocationSource` 隔离设备权限与定位，纯 Dart 的 `NearbyTransportProvider`
提供会话传输接口；`packages/ditmesh_chat` 拒绝对已失效会话调用原生接口。
Android 使用系统 LocationManager 和前台粗略/精确定位权限；Apple 提供本地化
权限说明，macOS 声明定位 entitlement，iOS 不申请始终定位。Linux 使用 GeoClue，
Windows 使用系统位置提供方。权限被拒绝或定位不可用时显示本地化恢复操作。

应用测试：在 `apps/ditmesh` 运行 `flutter test test/nearby`。底层适配器测试为
`packages/ditmesh_chat/test/nearby_transport_test.dart`。本功能遵守现有本地化、SDK
导入隔离和文件大小门禁。
