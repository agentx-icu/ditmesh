# DitMesh signal-tower icon candidates

Four editable vector candidates combine a signal tower with Morse dots/dashes. They retain the teal/white palette. Selected C now supplies all platform resources.

**Selected: C, the solid tower.** The other candidates remain as design records.

![Four icon candidates](options.png)

| Candidate | Design | Source |
|---|---|---|
| A | Radio tower, paired waves and separate Morse marks | [SVG](option-a.svg) |
| B | Dots/dashes form the broadcast signal | [SVG](option-b.svg) |
| C | Solid tower with Morse cutouts, strong at small sizes | [SVG](option-c.svg) |
| D | Circular radio badge for compact contexts | [SVG](option-d.svg) |

The Morse pattern is `−··` (D). Each has a 512px PNG preview; the comparison includes 64/32/16px sizes. The selected [coverage SVG](../../../apps/ditmesh/icon/signal_tower_mask.svg) and its 1024px mask feed [the app generator](../../../tool/gen_app_icons.dart) and [the tray generator](../../../tool/gen_tray_icons.dart). These generate 57 resources: opaque iOS icons, macOS tiles, Android adaptive and monochrome notification icons, Linux launcher icons, Windows ICOs, and tray variants.

The iOS PNGs are opaque; template/notification glyphs use alpha; both ICOs include their declared sizes. The [product concept](../product-2026-10-08/README.md) also uses C.
