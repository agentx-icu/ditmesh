# DitMesh signal-tower icon

The app icon combines a solid signal tower with Morse `−··` (D), using teal and white. Its broad silhouette keeps it legible at small sizes.

![Icon designs](options.png)

| Design | Shape | Vector source |
|---|---|---|
| A | Radio tower with waves and Morse marks | [SVG](option-a.svg) |
| B | Dots/dashes form the broadcast signal | [SVG](option-b.svg) |
| C — app icon | Solid tower with Morse cutouts | [SVG](option-c.svg) |
| D | Circular radio badge | [SVG](option-d.svg) |

Each design has a 512px preview; the board also shows 64/32/16px sizes. Platform resources are generated from the [shared mask](../../../apps/ditmesh/icon/signal_tower_mask.svg) using the [app generator](../../../tool/gen_app_icons.dart) and [tray generator](../../../tool/gen_tray_icons.dart).
