# DitMesh signal-tower icon candidates

Four editable vector candidates combine a signal tower with Morse dots/dashes. They retain the teal/white palette; platform resources have not been replaced yet.

**Selected: C, the solid tower.** The other candidates remain as design records.

![Four icon candidates](options.png)

| Candidate | Design | Source |
|---|---|---|
| A | Radio tower, paired waves and separate Morse marks; recommended | [SVG](option-a.svg) |
| B | Dots/dashes form the broadcast signal | [SVG](option-b.svg) |
| C | Solid tower with Morse cutouts, strong at small sizes | [SVG](option-c.svg) |
| D | Circular radio badge for compact contexts | [SVG](option-d.svg) |

The Morse pattern is `−··` (D). Each has a 512px PNG preview; the comparison includes 64/32/16px sizes. Once selected, one geometry must generate the opaque iOS icon, macOS icon, Android adaptive foreground and monochrome notification icon, Windows ICO and tray variants.
