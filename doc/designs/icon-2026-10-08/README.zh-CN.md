# DitMesh 信号塔图标候选

用户要求将当前图标换成「信号塔 + Morse 点划」。以下四个候选沿用深青色与白色，使用可编辑 SVG 几何；尚未替换平台应用资源。

**已选择 C：实心信号塔。** 其他方案保留为设计记录。

![四个图标候选](options.png)

| 方案 | 特点 | 源文件 |
|---|---|---|
| A 信号塔发报 | 经典无线电塔、两组电波与独立点划；推荐作为应用图标 | [SVG](option-a.svg) |
| B 点划电波 | 将点划放进发射信号，更突出 Morse 聊天 | [SVG](option-b.svg) |
| C 实心信号塔 | 大面积轮廓，点划镂空，适合小尺寸 | [SVG](option-c.svg) |
| D 无线电徽章 | 圆形徽章结构，适合托盘与标识 | [SVG](option-d.svg) |

点划采用 `−··`（D）。每项包含 512px PNG 预览，比较图包含 64/32/16px 小尺寸。选择后，平台资源应由同一几何源生成，包括透明单色托盘/通知图标、Android 自适应前景、iOS 不透明图标、macOS 图标与 Windows ICO。
