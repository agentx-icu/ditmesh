# DitMesh 发布与商店准备

DitMesh 五个平台统一是 Tox Morse 聊天应用，不再提供离线 iOS 学习变体；学习由独立 MorseCQ 负责。本清单说明准备工作，不代表已获商店批准或已有上架记录。

## 仓库发布

核对 tag/版本/build 元数据；通过必要分析、测试、原生库和应用构建；检查安装包内 FFI/运行时、独立应用标识与 SHA256SUMS；公开前审阅 GitHub 草稿 Release。未签名或未公证的包不能标记为已签名/公证。更新中英文截图，验证旧备份主动导入、离线队列、联系人、群组、屏蔽和删除数据。

## 所有者凭据及外部操作

| 平台 | 所有者工作 |
|---|---|
| iOS | `icu.agentx.ditmesh` 的 App Store Connect 记录、Team、分发证书/描述文件、签名归档与上传 |
| macOS | Developer ID 签名、公证及分发审核 |
| Android | 发布/上传密钥、商店账号、APK/AAB 签名 |
| Windows / Linux | 安装包运行验证及可选发行者签名 |

仓库不保存凭据；未签名 iOS 包安装前需要签名。

## 产品与隐私

输入只能是 Morse；没有手机号/邮箱注册或开发者聊天服务器。iOS 仍然包含 Tox 身份与加密点对点联网，不能沿用旧离线学习版的加密问卷答案，需依据实际原生库填写当前问卷。

摄像头用于二维码，麦克风用于本地译码，通知为本地提示。[隐私](../../site/zh-CN/privacy.md)、[条款](../../site/zh-CN/terms.md)、[支持](../../site/zh-CN/support.md)要与发版一致；Pages 部署是单独仓库设置/操作。

应用有屏蔽功能，但没有能从所有节点删除内容的中心服务；商店分发适合性需结合当前规则和实际点对点管理方式评估，本次不声明已经批准。

## 真机检查

检查侧音延迟、静音键、震动、触摸/键盘输入、二维码权限/摄像头、通知启动跳转、群组持久化、后台限制和口令/文件备份操作。模拟器截图不能替代真机。已执行结果见[验证记录](../VALIDATION.zh-CN.md)。
