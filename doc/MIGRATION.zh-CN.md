# 从 MorseCQ 迁移聊天到 DitMesh

MorseCQ 是离线学习应用，DitMesh 是只能用 Morse 输入的 Tox 聊天应用。两者应用标识与数据目录独立，不会自动打开对方的账号。

## 已使用 MorseCQ 聊天的用户

1. 升级 MorseCQ 离线版前，先在旧应用「我的」中导出加密备份，按需包含身份、联系人/群组、历史、草稿/书签和未发送消息。妥善保管文件和口令。
2. 安装 DitMesh，在欢迎页选择恢复并导入该文件。恢复逻辑主动兼容旧 MorseCQ 备份；新导出的备份标识为 DitMesh。
3. 检查恢复预览、组件选择和报告。未发送消息恢复后需要复核，不会自动发送。连接网络，确认好友及群组后再继续聊天。
4. 保留源备份和 MorseCQ 文件，直到聊天与学习数据均已核对。导入 DitMesh 不会删除源应用或文件。
5. 再把 MorseCQ 升级为离线学习版。原本地访客学习目录保留；旧身份关联的学习文件可通过显式导入功能复制到本地学习档案。

旧 `.tox` 文件只包含身份材料，不是完整历史、材料、偏好备份。Tox ID 是公开联系方式，不能恢复私钥。DitMesh 无法找回丢失的备份口令。

## 学习数据

MorseCQ 保留原 `<support>/morsecq/guest/` 目录。旧账号下的学习文件留在磁盘，离线版可主动选择并导入，无需连接 Tox 或加载私密身份文件。导入验证并复制学习文件，不删除源数据；不能未经用户明确选择覆盖已有目标数据。录音与相对路径引用需要一并保留。

不同平台的应用支持目录不同，请使用系统文件选择/导出工具，不要假设桌面路径也适用于手机。

## 协议与隐私

DitMesh 沿用 Tim2Tox v1 文本线路协议。恢复档案中的身份和群 ID 不因应用改名而改变。DitMesh 使用 Tox 网络；MorseCQ 学习不需要聊天网络。参见[隐私说明](../site/zh-CN/privacy.md)。
