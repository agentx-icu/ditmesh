# CI budget implementation plan

Goal: run Linux quality and real native regression checks once on ordinary PRs, without paying for every platform and installer on each edit.

Architecture: Native is the sole automatic caller of reusable Analyze. Ordinary runs build Linux x86_64 FFI, compile the real-backend Linux app and exercise native encryption/persistence plus real UDP peer regressions. The complete native matrix, platform installers and symbol pairing require manual dispatch, a current `ci:build` / `ci:full` label on a ready PR, or a version tag. Release tags retain every existing signature, ABI, integrity and asset-completeness gate.

1. Remove duplicate Analyze triggers; choose Linux or full native matrix and gate downstream platform app/installer jobs consistently.
2. Keep overlay, API and native regression coverage automatic; preserve native artifact producers needed by the Linux consumer.
3. Gate layout and harden E2E/visual/experimental ARM events for current labels, synchronize and ready-for-review, excluding drafts. Cancel superseded non-release work.
4. Use 3-day PR/push artifacts, 14-day full validation and the original tagged release retention. Add Pages timeouts while preserving safe deployment concurrency.
5. Run actionlint, relevant existing workflow/release tests and event/dependency checks. No cloud dispatch while Actions is disabled.

Implementation and verification results are recorded in the PR description. This change does not modify application code.

Label removal and conversion to draft cancel obsolete heavy PR work. A remaining opt-in label still applies. Unrelated label events skip in an isolated concurrency group, leaving existing quality/native or full runs intact.
