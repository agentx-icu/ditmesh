최종 업데이트: 2026-11-13

DitMesh는 Android, iOS, macOS, Linux, Windows에서 사용할 수 있는 P2P 모스 부호 채팅 앱입니다. 개발자가 운영하는 메시지 서버나 중앙 등록, 광고는 없습니다. 기술 지원은 공개 GitHub 이슈를 통해 제공됩니다. 비공개 메시지, 신원 정보 또는 백업을 그곳에 게시하지 마세요.

Android 릴리스 빌드는 Tox 백엔드를 시작하기 전에 개인정보 처리방침에 대한 동의를 요청합니다. 앱은 동의한 처리방침 버전을 기기에 저장하고, 버전이 바뀌면 다시 동의를 요청합니다.

기기에 저장되는 데이터

앱은 사용자의 Tox 신원 정보, 연락처, 그룹, 메시지 기록, 초안, 북마크, 연습 데이터, 환경설정, 키 바인딩, 저장한 녹음 파일을 앱 전용 저장소에 보관합니다. 신원 프로필은 비밀번호로 보호할 수 있습니다. 메시지 기록과 연습 파일은 기기에 저장될 때 암호화되지 않으므로 기기 접근과 백업을 주의해서 관리해야 합니다. 암호화된 내보내기 파일은 사용자가 요청할 때만 저장하거나 공유합니다.

부트스트랩 설정은 이 앱 설치에서 공통으로 사용합니다. 데스크톱에서 LAN 노드를 호스팅할 때는 별도의 로컬 노드 프로필을 사용합니다. 채팅에 사용하는 신원 정보를 변경하거나 삭제해도 이러한 네트워크 설정은 유지됩니다.

‘내 정보 → 신원 정보 삭제’에서 해당 신원에 연결된 기기 내 계정 데이터를 삭제할 수 있습니다. 이미 보낸 메시지는 받은 사람의 기기에 남습니다. 운영체제 백업과 이전에 내보낸 사본에는 각각의 보관 규칙이 적용됩니다. DitMesh와 MorseCQ는 앱 데이터를 별도로 보관합니다.

네트워크 데이터

메시지와 프로필 정보는 Tox 암호화를 사용해 연락처나 그룹에 전송됩니다. 네트워크는 공개 부트스트랩 노드를 사용해 피어를 찾습니다. 배달되지 않은 메시지를 보관하는 개발자 서버는 없습니다. 오프라인 상태에서 보낸 메시지는 양쪽 피어가 모두 연결 가능해질 때까지 보낸 사람의 기기에서 대기합니다.

자동 부트스트랩을 실행하거나 사용자가 목록을 직접 새로 고치면 https://nodes.tox.chat/json 주소로 공개 노드 목록을 요청합니다. 이때 해당 서버에 접속 IP 주소가 전달됩니다. 노드를 테스트할 때는 선택한 주소에 DHT 요청을 보냅니다. 데스크톱에서 LAN 노드를 호스팅하면 UDP 소켓을 열고, 사용자가 공유할 수 있도록 로컬 네트워크 주소와 공개 DHT 키를 표시합니다. 이러한 노드 정보에는 채팅 신원의 비밀 정보가 포함되지 않습니다.

Tox는 친구를 직접 연결하며 서로의 IP 주소를 숨기지 않습니다. 부트스트랩 및 DHT 노드는 임시 DHT 키를 사용하는 네트워크 연결을 확인할 수 있습니다. 공개 Tox ID만으로는 사용자의 신원 비밀 키가 노출되지 않습니다. 표시 이름, 상태, 그룹 메시지는 그 정보를 받도록 지정된 피어에게 표시됩니다.

Android에서는 Google ML Kit로 기기에서 QR 코드를 스캔합니다. Google은 앱 버전, 기기 정보, 스캔 성능 등의 진단 및 사용 지표를 받습니다. 카메라 이미지와 해독한 QR 코드 내용은 기기에서 처리되며 Google로 전송되지 않습니다.

위치 정보와 주변 사람

위치 정보와 주변 사람에게 내 정보를 표시하는 기능은 각각 따로 설정할 수 있는 선택 사항입니다. 두 기능 모두 이 기기의 각 신원에서 기본적으로 꺼져 있습니다. 현재 좌표는 Maidenhead 그리드 도구에 입력할 수 있습니다. 아직 보내지 않은 좌표는 메모리에 보관되며, 내보낸 백업에는 포함되지 않습니다. 사용자가 좌표를 미리 확인한 뒤 연락처나 그룹에 해당 위치를 담은 메시지 한 건을 직접 보낼 수 있습니다. 그 메시지는 각 수신자의 기기에서 채팅 기록에 보관되며, 해당 기록을 백업할 때 포함됩니다. 받은 위치를 확인할 때는 내 기기의 위치를 읽지 않습니다. 사용자가 지도를 열기로 선택한 경우에만 선택한 좌표가 지도 서비스 제공업체에 전달됩니다. 위치 정보는 앱이 포그라운드에 있을 때만 읽습니다.

주변 사람에게 내 정보를 표시하는 기능도 켠 상태에서 ‘주변 사람’을 열면 DitMesh는 Toxee와 같은 Tox 랑데부 프로토콜을 사용합니다. DitMesh는 표시 이름과 약 100 m 단위로 반올림한 대략적인 좌표를 해당 지역의 공개 Tox 그룹에 공유합니다. 이 그룹에 참여하는 사람은 누구나 이 정보를 받을 수 있습니다. 참여할 때 신원이나 실제 위치를 증명할 필요는 없습니다. 주변 사람 탐색에 쓰이는 패킷은 일반 채팅, 메시지 기록 또는 그룹 목록에 들어가지 않습니다. 위치 목록을 관리하는 서버는 없습니다. 네트워크 사업자와 운영체제의 위치 서비스 제공업체는 각자의 시스템을 통해 네트워크 연결 및 위치 요청을 파악할 수 있습니다.

주변 사람을 찾는 세션마다 탐색용 서명과 암호화에 사용할 새 신원을 생성합니다. 사용자가 주변 사람에게 직접 요청을 보내거나 응답할 때만 상대에게 Tox ID를 공개합니다. 요청은 선택한 참가자를 대상으로 암호화되며, 친구가 되려면 상대의 수락이 여전히 필요합니다. ‘주변 사람’ 화면을 닫으면 5분 후에 탐색을 중단합니다. 앱을 숨기거나 일시 중단하는 경우, 위치 또는 주변 사람 표시를 끄는 경우, Tox 세션을 종료하는 경우에는 즉시 중단합니다. 세션 기록은 만료되지만, 다른 참가자가 받은 정보를 보관할 수 있습니다. 탐색 중 차단은 현재의 임시 탐색 신원과 세션에만 적용됩니다. 일반 채팅에서의 차단은 별도로 적용됩니다.

선택 권한

• 로컬 네트워크(Apple 플랫폼): 수동으로 설정한 LAN 노드에 연결하거나 데스크톱에서 LAN 노드를 호스팅할 때 사용합니다.
• 위치: 현재 좌표 확인, 그리드 로케이터, 사용자가 직접 선택한 채팅 위치 공유, 선택 사항인 ‘주변 사람’ 기능에 사용합니다. 백그라운드 위치 권한은 요청하지 않습니다.
• 카메라: 기기에서 Tox ID의 QR 코드를 스캔합니다.
• 마이크: 기기에서 모스 부호 오디오를 해독합니다. 사용자가 요청할 때만 녹음을 저장합니다.
• 알림: 기기에서 메시지 수신을 알리고 관련 화면으로 이동할 때 사용합니다. 푸시 서버는 없습니다.
• 파일 선택 및 공유: 사용자가 직접 백업과 학습 자료를 가져오거나 내보낼 때 사용합니다. 선택한 클라우드 파일 서비스나 브라우저에서 열기로 한 링크는 각 제공업체의 네트워크 서비스를 사용합니다.

차단 및 변경 사항

상대방을 차단하면 해당 사용자의 메시지, 요청 및 초대가 이 기기에서 숨겨집니다. 다른 피어의 기기에 저장된 메시지를 삭제할 수 있는 중앙 운영자는 없습니다. 데이터 처리 방식이 바뀌면 이 문서에 반영하고 업데이트 날짜를 변경합니다.

문제 해결 방법은 ‘내 정보 → 개인정보 및 권한 → 기술 지원’을 참고하세요.
