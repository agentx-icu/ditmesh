DitMesh は、Android、iOS、macOS、Linux、Windows で動作する、ピアツーピア方式のモールス信号チャットアプリです。開発者が運営するメッセージサーバー、中央でのユーザー登録、広告はありません。サポートには公開の GitHub Issues を使用します。非公開のメッセージ、ID 情報、バックアップは投稿しないでください。

Android のリリース版では、Tox バックエンドを起動する前にプライバシーポリシーへの同意を求めます。アプリは同意済みのポリシーの版を端末に記録し、その版が変わると再度同意を求めます。

端末内のデータ

アプリは、Tox の ID 情報、連絡先、グループ、メッセージ履歴、下書き、ブックマーク、練習データ、設定、キーバインド、保存した録音をアプリ専用の領域に保存します。ID プロファイルはパスワードで保護できますが、保存されたメッセージ履歴や練習用ファイルは暗号化されません。そのため、端末へのアクセスとバックアップの管理には注意が必要です。暗号化されたエクスポートファイルは、ユーザーが明示的に指定した場合にのみ保存または共有されます。

ブートストラップ設定は、同じインストール内で共有されます。デスクトップでの LAN ホスティングには、別のローカルノード用プロファイルを使用します。チャットの ID を変更または削除しても、これらのネットワーク設定は保持されます。

「自分 → ID 情報を削除」で、その ID に関連する端末内のアカウントデータが削除されます。送信済みのメッセージは受信者の端末に残ります。OS によるバックアップや、以前エクスポートしたコピーには、それぞれの保存ルールが適用されます。DitMesh と MorseCQ は別々にアプリデータを保持します。

ネットワークデータ

メッセージやプロフィール情報は、Tox の暗号化を利用して連絡先やグループに送信されます。ネットワークは公開ブートストラップノードを使ってピアを見つけます。未配信のメッセージを保管する開発者サーバーはありません。オフライン時のメッセージは、両方のピアが通信可能になるまで送信者の端末で待機します。

自動ブートストラップ時、およびユーザーがノード一覧を更新したときには、https://nodes.tox.chat/json から公開ノード一覧を取得します。そのサーバーは接続元の IP アドレスを受け取ります。ノードのテストでは、選択したアドレスに DHT リクエストを送信します。デスクトップでの LAN ホスティングでは、UDP ソケットを開き、共有できるローカルネットワークのアドレスと公開 DHT 鍵を表示します。これらのノード情報には、チャット ID の秘密情報は含まれません。

Tox は友達同士を直接接続し、互いの IP アドレスを隠しません。ブートストラップノードや DHT ノードからは、一時的な DHT 鍵を使ったネットワーク接続を確認できます。公開 Tox ID だけでユーザーの ID の秘密鍵が明らかになることはありません。表示名、ステータス、グループメッセージは、対象となるピアに表示されます。

Android では Google ML Kit が端末上で QR コードを読み取ります。アプリのバージョン、端末情報、読み取り性能などの診断・利用状況の指標は Google に送信されます。カメラの画像と読み取った QR コードの内容は端末内で処理され、Google には送信されません。

位置情報と「近くの人」

位置情報の利用と、近くの人に自分を表示する設定は、それぞれ独立した任意の設定です。この端末上の ID ごとに、初期設定ではどちらもオフになっています。現在の座標は Maidenhead グリッドロケーターに入力できます。送信していない座標はメモリ内に保持され、エクスポートしたバックアップには含まれません。座標をプレビューしたうえで、連絡先やグループにその時点の位置を 1 件のメッセージとして明示的に送信できます。そのメッセージは各受信者の端末にチャット履歴として保存され、その履歴をバックアップするときに含まれます。受信した位置を確認する際に、この端末の位置情報は取得されません。地図を開く操作をした場合に限り、選択した座標が地図サービスの提供元に送られます。位置情報の取得は、アプリがフォアグラウンドにある間に限られます。

近くの人に自分を表示する設定もオンにして「近くの人」を開くと、DitMesh は Toxee と同じ Tox ランデブープロトコルを使用します。DitMesh は表示名とおおよその座標（約 100 m 単位に丸めたもの）を、利用者のエリアに対応する公開 Tox グループで共有します。グループに参加した人は誰でもこれらの情報を受け取れます。参加に本人確認や実際の所在地の証明は不要です。「近くの人」の通信パケットは、通常のチャット、メッセージ履歴、グループ一覧には入りません。位置情報の一覧を管理するサーバーはありません。ネットワーク事業者や OS の位置情報サービスの提供元は、それぞれの仕組みに応じて、ネットワーク接続や位置情報のリクエストを把握できます。

近くの人を探すセッションごとに、探索用の署名と暗号化に使う新しい ID を作成します。Tox ID は、近くの人へのリクエストを明示的に送信または返信した場合に限り、相手に開示されます。リクエストは選択した参加者に向けて暗号化され、友達になるには引き続き承認が必要です。「近くの人」画面を閉じると 5 分後に探索が終了します。アプリを非表示にするか一時停止した場合、位置情報または近くの人に自分を表示する設定をオフにした場合、Tox セッションを終了した場合は、探索が直ちに停止します。セッションの記録は期限切れになりますが、ほかの参加者が受け取った情報を保持する場合があります。探索でのブロックは、現在の一時的な探索用 ID とセッションにのみ適用されます。通常のチャットでのブロックは別に管理されます。

任意の権限

• ローカルネットワーク（Apple プラットフォーム）：手動で設定した LAN ノードへの接続や、デスクトップでの LAN ノードのホスティングに使用します。
• 位置情報：現在の座標の取得、グリッドロケーター、チャットでの明示的な位置情報の共有、任意の「近くの人」機能に使用します。バックグラウンドでの位置情報の権限は要求しません。
• カメラ：端末上で Tox ID の QR コードを読み取ります。
• マイク：端末上でモールス信号の音声を解読します。録音は、ユーザーが指定した場合にのみ保存します。
• 通知：端末上でメッセージの着信を知らせ、関連する画面に移動できるようにします。プッシュ通知サーバーはありません。
• ファイル選択と共有：ユーザーが明示的にバックアップや教材をインポートまたはエクスポートするために使用します。選択したクラウドファイルサービスや、ブラウザーで開くリンクの提供元は、それぞれ独自のネットワークサービスを使用します。

ブロックと変更

相手をブロックすると、その相手のメッセージ、リクエスト、招待がこの端末で非表示になります。別のピアの端末に保存されたメッセージを削除できる中央の運営者はいません。データの取り扱いが変更された場合は、ここに反映し、更新日を改めます。

トラブルシューティングについては「自分 → プライバシーと権限 → 技術サポート」をご覧ください。
